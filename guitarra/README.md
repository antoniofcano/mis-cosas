# Guitarra

Maquetas de estudio de las clases de guitarra flamenca. Cada carpeta es una
página estática que se abre en el navegador.

| Carpeta | Qué es |
|---|---|
| [`estrella-morente/`](estrella-morente/) | «Estrella» de Enrique Morente (tango): vídeo sincronizado con la pizarra de letra y acordes |
| [`clase-tangos/`](clase-tangos/) | Clase de tangos por medio: compás, ruedas, escala y falseta nota a nota sobre el mástil |

Las dos vinieron de una rama de experimento de `olivartrack`, que ya se ha
borrado allí.
